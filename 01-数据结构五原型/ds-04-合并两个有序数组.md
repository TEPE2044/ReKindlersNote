# 卷一 · 数据结构 04：合并两个有序数组

> 双指针的另一种用法：不是从两头往中间，而是两队各出一个比大小。

## 为什么学

两份按时间排好的测试报告，合成一份时间线；两段已排序的日志，合成一段。用循环硬插太慢，双指针各扫一遍就能做完。

这也是面试里的基础原型题。

## 思路

两个数组都已经排好序。各放一个指针，每次取较小的那个放进新数组，指针前进。一个数组用完，把另一个数组剩下的直接接上去。

```js
function merge(a, b) {
  let i = 0, j = 0;
  const out = [];

  while (i < a.length && j < b.length) {
    if (a[i] < b[j]) {
      out.push(a[i]);
      i++;
    } else {
      out.push(b[j]);
      j++;
    }
  }

  while (i < a.length) {
    out.push(a[i]);
    i++;
  }

  while (j < b.length) {
    out.push(b[j]);
    j++;
  }

  return out;
}

console.log(merge([1, 3, 5], [2, 4, 6])); // [1, 2, 3, 4, 5, 6]
```

## 坑

- 循环条件是两个数组都还有剩。只要其中一个空了，就要退出主循环，把另一个剩下的直接接过去。
- 不要一个数组空了还在比较 `a[i] < b[j]`，会拿到 `undefined`。
- 合并后的数组必须仍然有序，这是验收标准。

## 练习

手写。

**Q1.** 写一个 `mergeDesc(a, b)`，合并两个**降序**数组，结果仍是降序。

验收：

```js
console.log(mergeDesc([5, 3, 1], [6, 4, 2])); // [6, 5, 4, 3, 2, 1]
console.log(mergeDesc([6, 4, 2], []));        // [6, 4, 2]
console.log(mergeDesc([5, 3, 1], [5, 2]));    // [5, 5, 3, 2, 1]
```

**Q2.** 写一个 `mergeUnique(a, b)`，合并两个升序数组，结果去重且升序。

验收：

```js
console.log(mergeUnique([1, 2, 3], [2, 3, 4])); // [1, 2, 3, 4]
console.log(mergeUnique([1, 1, 2], [1, 3]));    // [1, 2, 3]
```

提示：主循环里取较小的那个之前，先看看它是否和 `out` 最后一个元素相同。

---

## 答案（先做完再看）

<details>
<summary>Q1 验收要点</summary>

- 主循环条件仍然是 `i < a.length && j < b.length`。
- 因为输入是降序，每次要取**较大**的那个放进结果。
- 主循环结束后，把剩余元素直接接上去。

</details>

<details>
<summary>Q2 验收要点</summary>

- 在 `out.push(x)` 前判断 `x !== out[out.length - 1]`。
- 两个收尾循环也要做同样判断。

</details>
