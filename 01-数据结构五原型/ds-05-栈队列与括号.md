# 第一章 · 数据结构 05：栈、队列、括号

> 上一课是两队各出一个比大小。这一课是只从一头拿。

## 为什么学

测试平台里两处用得上：失败用例按入队顺序重跑，是队列；解析一行断言表达式里的括号，是栈。不要另找一道和你无关的算法题。

## 栈：后进先出

数组当栈，只用 `push` 和 `pop`。不要用 `shift`，那是从另一头拿。

```js
const stack = [];
stack.push("(");
stack.push("[");
console.log(stack.pop()); // [
console.log(stack.pop()); // (
console.log(stack.pop()); // undefined，空栈再 pop 不报错
```

空栈 `pop()` 得到 `undefined`，和数组越界一样。不先判断长度，后面的比较会悄悄错。

## 括号匹配

从左到右扫。左括号入栈，右括号必须和栈顶那对上，对上就弹出。扫完栈必须是空的。

```js
function isBalanced(s) {
  const pair = { ")": "(", "]": "[", "}": "{" };
  const stack = [];

  for (const ch of s) {
    if (ch === "(" || ch === "[" || ch === "{") {
      stack.push(ch);
      continue;
    }
    if (!(ch in pair)) continue;
    if (stack.pop() !== pair[ch]) return false;
  }
  return stack.length === 0;
}

console.log(isBalanced("()[]{}")); // true
console.log(isBalanced("(]"));     // false
console.log(isBalanced("([)]"));   // false
console.log(isBalanced(""));       // true
```

`([)]` 是这题唯一要看懂的例子：`]` 弹出时栈顶是 `[` 不是 `(`，交叉了，直接 false。不是「左右数量一样就行」。

## 队列：先进先出

测试步骤按收集顺序重跑，用队列。`push` 进队，`shift` 出队。

```js
const q = [];
q.push("打开琴键页");
q.push("点录音");
q.push("断言电平条出现");

while (q.length) {
  console.log(q.shift());
}
```

`shift` 在很长的数组上慢，测试步骤几十条无所谓。不要为了这个去写链表队列。

## 坑

- 空栈 `pop()` 返回 `undefined`，不会崩。但扫完后必须检查 `stack.length === 0`，否则只有左括号的字符串（如 `"(("`）会被误判为合法。
- `([)]` 数量平衡，顺序不平衡。
- 队列不要用 `pop` 出队，那又变回栈了。

## 练习

手写。不要抄上面的函数。验收用 `node` 看打印。

**Q1.** 写 `checkParens(s)`，只检查圆括号 `()` 是否匹配。如果匹配返回 `-1`；如果不匹配，返回第一个出错位置的下标。

验收：

```js
console.log(checkParens("()"));       // -1
console.log(checkParens("(())"));     // -1
console.log(checkParens("(()"));      // 0（左括号没配成对）
console.log(checkParens("())"));      // 2（右括号没配成对）
console.log(checkParens("a(b)c"));    // -1
```

**Q2.** 写 `replay(steps)`。入参是字符串数组，按原顺序打印每一条，打印完原数组还在（不要改入参）。

```js
const steps = ["打开琴键页", "点录音", "断言电平条出现"];
replay(steps);
console.log(steps.length); // 3
```

**Q3.** 写一个 `Queue` 类，支持 `enqueue(x)`、`dequeue()`、`peek()`、`isEmpty()`。

验收：

```js
const q = new Queue();
q.enqueue(1);
q.enqueue(2);
console.log(q.peek());    // 1
console.log(q.dequeue()); // 1
console.log(q.dequeue()); // 2
console.log(q.isEmpty()); // true
console.log(q.dequeue()); // undefined
```

## 答案（先做完再看）

<details>
<summary>Q1 验收要点</summary>

- 只处理 `(` 和 `)`，非括号字符跳过。
- 遇到 `(` 入栈，遇到 `)` 时如果栈空，说明这个右括号没配成对，返回当前下标。
- 扫完后如果栈不空，说明有左括号没配成对，返回栈底剩下的那个左括号的下标（即最早没配对的那个）。
- 都匹配才返回 -1。

</details>

<details>
<summary>Q2 验收要点</summary>

- 用 `[...steps]` 或 `steps.slice()` 复制一份再 `shift`，不要改入参。
- 也可以用一个索引变量 `i` 顺序访问原数组，不改它。

</details>

<details>
<summary>Q3 验收要点</summary>

- `enqueue` 用 `push`。
- `dequeue` 用 `shift`，空队列返回 `undefined`。
- `peek` 返回 `this.items[0]`，不弹出。

</details>
