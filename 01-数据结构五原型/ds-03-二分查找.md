# 第一章 · 数据结构 03：二分查找

> 数组有序，就不用一个个找了。

## 为什么学

测试日志、结果列表、按时间排序的用例，常常是有序的。从头扫到尾太慢，二分能把 `n` 降到 `log₂n`。1000 条查 10 次就定位。

面试也爱考，因为它把"边界"这件事考得很清楚。

## 基本写法

```js
function search(arr, target) {
  let left = 0;
  let right = arr.length - 1;

  while (left <= right) {
    const mid = Math.floor((left + right) / 2);

    if (arr[mid] === target) return mid;
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}

console.log(search([1, 3, 5, 7, 9, 11], 7)); // 3
console.log(search([1, 3, 5, 7, 9, 11], 4)); // -1
```

## 三个注意点

1. **循环条件是 `left <= right`**，不是 `<`。因为二分要检查中间那一格，不能漏。
2. **`Math.floor` 要写。** 虽然 JS 数很大时 `left + right` 也不容易溢出，但养成习惯。
3. **找不到时返回 -1 还是插入位置，题目说了算。** 这里只写最简单的返回 -1。

## 和双指针的区别

上一课翻转数组用 `i < j`，这里用 `left <= right`。两个条件不一样，别互抄。

- `i < j`：两个指针往中间挤，碰头就停，中间那格不用处理。
- `left <= right`：左右包围一个区间，中间那格必须检查。

## 坑

- `mid` 算完之后，如果 `arr[mid]` 不是答案，必须让 `left` 或 `right` 跳过 `mid`。写成 `left = mid` 或 `right = mid` 会死循环。
- 数组必须有序。无序数组用二分，结果不可预期。

## 练习

手写。

**Q1.** 写一个 `searchFirst(arr, target)`，返回目标第一次出现的下标。

验收：

```js
console.log(searchFirst([1, 2, 2, 2, 3], 2)); // 1
console.log(searchFirst([1, 2, 2, 2, 3], 4)); // -1
console.log(searchFirst([], 4));              // -1
```

提示：找到 `arr[mid] === target` 时不要立刻返回，先把 `right` 往左压，继续查左半边。

**Q2.** 写一个 `lowerBound(arr, target)`，返回第一个**大于等于** `target` 的下标。如果所有元素都小于 `target`，返回 `arr.length`。

验收：

```js
console.log(lowerBound([1, 3, 5, 7, 9], 5));  // 2
console.log(lowerBound([1, 3, 5, 7, 9], 4));  // 2（4 该插在 5 的位置）
console.log(lowerBound([1, 3, 5, 7, 9], 0));  // 0
console.log(lowerBound([1, 3, 5, 7, 9], 10)); // 5
console.log(lowerBound([], 1));               // 0
```

## 答案（先做完再看）

<details>
<summary>Q1 验收要点</summary>

- 相等时先记录答案，再 `right = mid - 1` 继续往左找。
- 循环结束后返回记录的下标，没找到返回 -1。

</details>

<details>
<summary>Q2 验收要点</summary>

- `left` 从 0 开始，`right` 从 `arr.length` 开始（不是 `length - 1`）。
- 循环条件 `left < right`。
- 如果 `arr[mid] >= target`，说明答案在左半边，令 `right = mid`；否则 `left = mid + 1`。
- 循环结束 `left` 就是插入位置。空数组返回 0。

</details>
