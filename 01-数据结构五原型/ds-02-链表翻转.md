# 第一章 · 数据结构 02：链表翻转

> 面试里说"翻转列表"，更常指这个。

## 为什么单独学

数组能两头走，是因为它有下标。链表只有 `next`，走不到后面。这迫使你换一种思路：**把 next 指回前一个**。

测试平台里的配置链、步骤链、断言链，本质都是链表。改一处的时候，你要知道为什么不会断。

## 链表的节点

一个节点存两样东西：值和下一个节点的引用。

```js
class ListNode {
  constructor(val, next = null) {
    this.val = val;
    this.next = next;
  }
}
```

几个节点连起来，就是一条链：

```js
const list = new ListNode(1, new ListNode(2, new ListNode(3)));
```

遍历只能从头走到尾：

```js
let p = list;
while (p) {
  console.log(p.val);
  p = p.next;
}
```

## 翻转

思路：让整条链掉头往回走。每个节点的 `next` 不再指向下一个，而是指回前一个。

```js
function reverseList(head) {
  let prev = null;
  let cur = head;

  while (cur) {
    const next = cur.next;  // ① 先记住下一个
    cur.next = prev;        // ② 掉头
    prev = cur;             // ③ prev 往前走
    cur = next;             // ④ cur 往前走
  }
  return prev;
}
```

第 ① 行是整段代码的命门。`cur.next = prev` 执行后，原来的下一个节点就找不到了。不先存，链从这里断掉。

## 坑

- 翻转前必须先保存 `cur.next`，否则后面的节点全部丢失。
- 返回的是 `prev`，不是 `cur`。循环结束时 `cur` 是 `null`。
- 空链表直接返回 `null`，不要让它进循环。

## 练习

手写。不要复制上面的函数。

**Q1.** 写一个 `copyAndReverse(head)`，返回一条新链表，是原链表的翻转，**原链表不能被修改**。

验收：

```js
const original = new ListNode(1, new ListNode(2, new ListNode(3)));
const reversed = copyAndReverse(original);

function toArray(head) {
  const out = [];
  let p = head;
  while (p) { out.push(p.val); p = p.next; }
  return out;
}

console.log(toArray(reversed));  // [3, 2, 1]
console.log(toArray(original));  // [1, 2, 3]，原链表没变
```

**Q2.** 把 `const next = cur.next;` 这行删掉，手动跑一次。观察输出，并写下为什么会这样。

**Q3.** 写一个 `hasCycle(head)`，判断链表是否有环。

验收：

```js
// 无环
const a = new ListNode(1, new ListNode(2, new ListNode(3)));
console.log(hasCycle(a)); // false

// 有环：尾节点连回头
const b = new ListNode(1);
const b2 = new ListNode(2);
const b3 = new ListNode(3);
b.next = b2;
b2.next = b3;
b3.next = b2; // 3 -> 2
console.log(hasCycle(b)); // true
```

提示：不需要修改链表结构。两个指针，一个每次走一步，一个每次走两步。

---

## 答案（先做完再看）

<details>
<summary>Q1 验收要点</summary>

- 必须创建新节点，不能直接修改原链表的 `next`。
- 思路仍然是三指针：遍历原链表，每次把当前值插入新链表的头部。
- 返回新链表的头节点。空链表直接返回 `null`。

</details>

<details>
<summary>Q2 观察</summary>

删掉 `const next = cur.next;` 后，代码执行到 `cur = next;` 时会抛 `ReferenceError: next is not defined`。因为 `next` 这个变量不存在，循环体根本没跑完，更谈不上翻转。

这也说明：改 `next` 之前必须先保存出路，否则后面的节点根本访问不到。

</details>

<details>
<summary>Q3 验收要点</summary>

- 快慢指针。`slow` 每次走一步，`fast` 每次走两步。
- 如果有环，两者终会相遇。
- 如果 `fast` 或 `fast.next` 为 `null`，说明无环。

</details>
