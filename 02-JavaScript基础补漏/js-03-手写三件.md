# 第二章 · JavaScript 03：手写三件

> 防抖、`reduce`、浅拷贝，东西不难，但每次手写都停在第一步。

## 为什么只写三件

手写题很容易变成炫技大会。你不需要学会所有。这三件在测试平台里天天见：

- 防抖：搜索框、连续点击。
- `reduce` 不给初始值：数组累加、分组、拍平。
- 浅拷贝边界：配置对象合并，JSON 拷不了的那些。

`myCall` / `myBind` 面试会问，但你先不碰。等这三件闭着眼睛能写，再加。

## 防抖 debounce

连续触发只认最后一次。等停下来才执行。

```js
function debounce(fn, wait) {
  let timer = null;

  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
    }, wait);
  };
}
```

要点：

- 每次触发先清掉上一次的定时器。
- 用 `fn.apply(this, args)` 保留调用时的 `this` 和参数。
- 返回一个新函数，不要直接改原来的 `fn`。

场景：搜索框输入时连续发请求，只等用户停下来 300ms 后再发。

## `reduce` 不给初始值

```js
const sum = [1, 2, 3].reduce((a, b) => a + b);
console.log(sum); // 6
```

不给初始值时，第一轮的 `a` 是数组第 0 个元素，`b` 是第 1 个。所以你看到 `1 + 2 + 3`，不是 `0 + 1 + 2 + 3`。

如果数组只有一个元素：

```js
const single = [5].reduce((a, b) => a + b);
console.log(single); // 5
```

直接返回那个元素，回调不会执行。

空数组会报错：

```js
[].reduce((a, b) => a + b); // TypeError
```

## 浅拷贝边界

```js
const a = { x: 1, y: { z: 2 } };
const b = { ...a };

b.x = 99;
console.log(a.x); // 1，没变

b.y.z = 99;
console.log(a.y.z); // 99，变了
```

展开运算符和 `Object.assign` 都是浅拷贝。嵌套对象共享引用。

平台里合并配置时，顶层 key 不会串，嵌套的 key 会串。这是真实 bug 来源。

```js
function cloneConfig(obj) {
  return JSON.parse(JSON.stringify(obj));
}
```

这个方法能处理普通对象、数组、基本类型，但会丢掉：

- 函数
- `undefined`
- 循环引用
- Date（变成字符串）
- RegExp（变成空对象）

平台配置里一般没有这些，够用了。但要知道边界在哪。

## 练习

手写。

**Q1.** 写一个 `debounce(fn, wait)`。

验收：

```js
let count = 0;
const inc = debounce(() => {
  count++;
}, 50);

inc();
inc();
inc();
console.log(count); // 0，50ms 内多次触发只认最后一次

setTimeout(() => {
  console.log(count); // 1
}, 100);
```

**Q2.** 用 `reduce` 写一个 `groupBy(arr, key)`，把对象数组按指定 key 分组。

验收：

```js
const users = [
  { role: "admin", name: "a" },
  { role: "user", name: "b" },
  { role: "admin", name: "c" },
];

console.log(groupBy(users, "role"));
// { admin: [{ role: "admin", name: "a" }, { role: "admin", name: "c" }], user: [{ role: "user", name: "b" }] }
```

**Q3.** 写一个 `shallowClone(obj)`，用 `Object.assign` 或展开实现。然后写一个测试，证明嵌套对象会被共享引用。

## 答案（先做完再看）

<details>
<summary>Q1 验收要点</summary>

- 返回新函数。
- 内部用 `clearTimeout(timer)` 清掉上次定时器。
- 用 `setTimeout` 重新设。
- 调用原函数时 `fn.apply(this, args)` 保留 `this` 和参数。

</details>

<details>
<summary>Q2 验收要点</summary>

- 用 `arr.reduce`，初始累加器是 `{}`。
- 每次取 `item[key]` 作为分组键。
- 如果该键还没有数组，先初始化为空数组，再 `push(item)`。
- 最后返回这个对象。

</details>

<details>
<summary>Q3 验收要点</summary>

- 用 `{ ...obj }` 或 `Object.assign({}, obj)` 做浅拷贝。
- 测试时修改拷贝后的嵌套对象，再检查原对象的同一嵌套字段是否也被修改。
- 如果原对象也被改了，说明嵌套对象是共享引用，这就是浅拷贝的边界。

</details>
