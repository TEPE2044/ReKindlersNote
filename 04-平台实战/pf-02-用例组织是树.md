# 第四章 · 平台实战 02：用例组织是树

> 测试平台里的用例不是平铺的，是嵌套的。树结构是平台改造的核心。

## 为什么学

`xinhuo_test_platform` 里的用例可能是这样：

```text
登录模块
├── 正常登录
└── 异常登录
    ├── 密码错误
    └── 账号锁定
```

平铺数组存不了这种关系。树一嵌套，遍历、查找、统计就要换思路。

## 树的节点

```js
const root = {
  id: "1",
  name: "登录模块",
  children: [
    { id: "2", name: "正常登录", children: [] },
    {
      id: "3",
      name: "异常登录",
      children: [
        { id: "4", name: "密码错误", children: [] },
        { id: "5", name: "账号锁定", children: [] },
      ],
    },
  ],
};
```

每个节点有 `id`、`name`、 `children`。`children` 为空数组就是叶子节点。

## 遍历：先序

```js
function traverse(node, visitor) {
  visitor(node);
  for (const child of node.children) {
    traverse(child, visitor);
  }
}

traverse(root, (n) => console.log(n.name));
// 登录模块、正常登录、异常登录、密码错误、账号锁定
```

先处理自己，再递归孩子。这是最常见的遍历方式。

## 查找某个 id 的节点

```js
function findNode(node, id) {
  if (node.id === id) return node;
  for (const child of node.children) {
    const found = findNode(child, id);
    if (found) return found;
  }
  return null;
}

console.log(findNode(root, "4").name); // 密码错误
```

递归返回结果时，要记得如果找到了就层层返回，不要继续扫。

## 统计叶子节点

```js
function countLeaves(node) {
  if (node.children.length === 0) return 1;
  return node.children.reduce((sum, child) => sum + countLeaves(child), 0);
}

console.log(countLeaves(root)); // 3
```

叶子节点就是能直接执行的用例。统计叶子数，等于统计可执行用例总数。

## 坑

- 递归一定要有终止条件，通常是 `children.length === 0`。
- 树的修改（删除、移动节点）比查找麻烦，最好先定位到父节点再操作。
- 如果树很深，递归可能栈溢出。但测试用例一般几十层，不用担心。

## 练习

手写。

**Q1.** 写一个 `getNames(node)`，返回树中所有节点 name 的数组（先序）。

验收：

```js
console.log(getNames(root));
// ["登录模块", "正常登录", "异常登录", "密码错误", "账号锁定"]
```

**Q2.** 写一个 `findParent(node, id)`，返回指定 id 节点的父节点。

验收：

```js
console.log(findParent(root, "4").name); // 异常登录
console.log(findParent(root, "1"));      // null（根节点没有父节点）
```

**Q3.** 写一个 `flattenLeaves(node)`，返回所有叶子节点的 name 数组。

验收：

```js
console.log(flattenLeaves(root));
// ["正常登录", "密码错误", "账号锁定"]
```

## 答案（先做完再看）

<details>
<summary>Q1 验收要点</summary>

- 先把自己 `node.name` 放进结果数组。
- 再遍历 `node.children`，递归每个孩子，把结果展开合并。
- 用展开运算符 `...` 或 `concat` 合并数组。

</details>

<details>
<summary>Q2 验收要点</summary>

- 遍历当前节点的每个孩子。
- 如果某个孩子的 `id` 等于目标，当前节点就是父节点，返回它。
- 如果当前层没找到，递归进每个孩子继续找；找到后层层返回，不要丢掉。
- 根节点没有父节点，最终返回 `null`。

</details>

<details>
<summary>Q3 验收要点</summary>

- 如果 `node.children.length === 0`，说明是叶子，返回 `[node.name]`。
- 否则递归每个孩子，把结果拍平成一个数组。
- 可以用 `flatMap` 简化。

</details>
