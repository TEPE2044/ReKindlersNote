# 卷三 · JavaScript 04：作用域与闭包

> 闭包的规则不复杂，关键是要自己写一遍。

## 为什么先学这个

之前写 Vue，变量该放 `data`、`computed` 还是函数里，框架帮你管。现在写测试脚本，没人替你管了。一个计数器、一个缓存、一组配置，放错地方就串。

## 三种作用域

```js
function outer() {
  var a = 1;      // 函数作用域
  let b = 2;      // 块作用域

  if (true) {
    var c = 3;    // 还是函数作用域，会提升到 outer 顶部
    let d = 4;    // 只在 if 块里
  }

  console.log(a); // 1
  console.log(b); // 2
  console.log(c); // 3
  // console.log(d); // ReferenceError
}
```

**var 的坑**：没有块级作用域，`if`、`for` 里用 `var` 声明的变量会泄漏到整个函数。

## 闭包不是复制，是引用

```js
function makeCounter() {
  let n = 0;
  return {
    inc: () => ++n,
    dec: () => --n,
    get: () => n,
  };
}

const c = makeCounter();
console.log(c.inc()); // 1
console.log(c.inc()); // 2
console.log(c.get()); // 2
```

`n` 在 `makeCounter` 执行完本应消失，但被返回的函数引用着，所以活下来了。闭包保存的是**变量本身**，不是快照。

## 循环里的 var

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 3 3 3
```

因为 `var i` 只有一个，循环结束时 `i = 3`。三个 setTimeout 共享同一个 `i`。

改成 `let`：

```js
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 0 1 2
```

每次迭代，`let` 都会创建一个新的 `i` 绑定。

## 坑

- `var` 会提升，可以先使用后声明，但值是 `undefined`。
- 闭包共享的是变量，如果你返回一组函数，它们可能共享同一个变量，而不是各拿一个副本。
- 不要为用闭包而用闭包。普通参数能解决的问题，不要包一层。

## 练习

手写。

**Q1.** 写一个 `makeCounter(start = 0)`，返回 `{ inc, dec, get }`。

验收：

```js
const c = makeCounter(10);
console.log(c.get());  // 10
console.log(c.inc());  // 11
console.log(c.inc());  // 12
console.log(c.dec());  // 11
```

**Q2.** 修复下面这段代码，让输出是 0、1、2，不能用 `let`。

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
```

提示：用闭包把每次的 `i` 包起来。

**Q3.** 写一个 `once(fn)`，让函数只执行一次，后续调用返回第一次的结果。

验收：

```js
let count = 0;
const inc = once(() => ++count);

console.log(inc()); // 1
console.log(inc()); // 1
console.log(inc()); // 1
console.log(count); // 1
```

## 答案（先做完再看）

<details>
<summary>Q1 验收要点</summary>

- 内部用 `let n = start`。
- `inc` 返回 `++n`，`dec` 返回 `--n`。
- 三个方法共享同一个 `n`。

</details>

<details>
<summary>Q2 验收要点</summary>

- 题目要求不能用 `let`，所以要用 IIFE 把每次循环的 `i` 值锁进新的作用域。
- IIFE 的参数接收当前 `i` 的值，内部 `setTimeout` 引用的是参数 `j`，不是外层共享的 `i`。
- 更简单也更推荐的做法是直接用 `let`。

</details>

<details>
<summary>Q3 验收要点</summary>

- 用闭包保存两个私有变量：`called`（是否调用过）和 `result`（第一次结果）。
- 返回的函数每次先检查 `called`；如果还没调用，就执行 `fn` 并缓存结果，同时把 `called` 置为 true。
- 后续调用直接返回缓存的 `result`，不再执行 `fn`。

</details>
