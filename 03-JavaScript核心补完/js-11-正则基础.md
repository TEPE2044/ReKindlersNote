# 卷三 · JavaScript 11：正则基础

> 测试日志里抓关键字、断言文本是否匹配、替换敏感信息，都要用到正则。

## 三种用法

```js
const re = /\d+/;

re.test("abc123");        // true，是否匹配
"abc123".match(re);       // ["123"]，返回匹配内容
"abc123".replace(re, "X"); // "abcX"，替换
```

## 常用元字符

| 元字符 | 含义 |
| --- | --- |
| `.` | 任意字符 |
| `\d` | 数字 |
| `\w` | 字母、数字、下划线 |
| `\s` | 空白字符 |
| `+` | 前面字符出现 1 次或多次 |
| `*` | 前面字符出现 0 次或多次 |
| `?` | 前面字符出现 0 次或 1 次 |
| `^` | 字符串开头 |
| `$` | 字符串结尾 |

## 测试里的例子

从日志里抓错误码：

```js
const log = "[ERROR] code=404, msg=not found";
const match = log.match(/code=(\d+)/);
console.log(match[1]); // 404
```

圆括号 `()` 是捕获组，`match[1]` 拿到第一个组的内容。

判断版本号格式：

```js
function isVersion(str) {
  return /^\d+\.\d+\.\d+$/.test(str);
}

console.log(isVersion("1.2.3")); // true
console.log(isVersion("v1.2.3")); // false
```

## 替换

把手机号中间四位打码：

```js
const phone = "13812345678";
const masked = phone.replace(/(\d{3})\d{4}(\d{4})/, "$1****$2");
console.log(masked); // 138****5678
```

`$1`、`$2` 对应捕获组。

## 坑

- 正则里的反斜杠在字符串里要转义：`new RegExp("\\d+")` 才等于 `/\d+/`。
- `.test()` 不会返回捕获组，要拿内容用 `.match()`。
- `^` 和 `$` 不注意，会匹配到不想要的子串。

## 练习

手写。

**Q1.** 写一个 `extractErrorCode(log)`，从日志字符串里提取 `code=数字` 中的数字。

验收：

```js
console.log(extractErrorCode("[ERROR] code=500"));        // "500"
console.log(extractErrorCode("[WARN] code=404, retry"));  // "404"
console.log(extractErrorCode("no code here"));            // null
```

**Q2.** 写一个 `maskPhone(phone)`，把手机号中间四位替换成 `****`。

验收：

```js
console.log(maskPhone("13812345678")); // "138****5678"
console.log(maskPhone("15987654321")); // "159****4321"
```

**Q3.** 写一个 `isValidEmail(email)`，简单判断邮箱格式。要求有 `@`，`@` 前后都有字符，`@` 后面有 `.`。

验收：

```js
console.log(isValidEmail("a@b.com"));  // true
console.log(isValidEmail("a@b"));      // false
console.log(isValidEmail("ab.com"));   // false
console.log(isValidEmail("@b.com"));   // false
```

## 答案（先做完再看）

<details>
<summary>Q1 验收要点</summary>

- 正则里用圆括号 `()` 把 `\d+` 包成捕获组。
- `log.match()` 返回的数组第 0 项是完整匹配，第 1 项是第一个捕获组。
- 没匹配到时返回 `null`，要处理这种情况。

</details>

<details>
<summary>Q2 验收要点</summary>

- 正则把 11 位手机号分成三部分：前三位、中间四位、后四位，都用捕获组。
- `replace` 的第二个参数用 `$1****$2` 保留前后，中间替换。

</details>

<details>
<summary>Q3 验收要点</summary>

- 正则要求 `@` 前后至少有一个非空白、非 `@` 的字符。
- `@` 后面要有一个点，点后也至少有一个字符。
- 这个规则不完美，但满足题目要求。不要写过度复杂的正则去覆盖所有邮箱变体。

</details>
