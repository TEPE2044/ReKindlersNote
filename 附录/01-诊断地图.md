## 需要改正的 9 题

| 题 | 你的答案 | 对的 | 一句原因 |
| --- | --- | --- | --- |
| `0.1 + 0.2 === 0.3` | true | **false** | 二进制浮点，实际是 `0.30000000000000004`。金额和断言用整数，或比较前先定精度 |
| 闭包 `c(); c(); console.log(c())` | 2 | **3** | `++n` 发生在每一次调用里，包括 `console.log` 里的那次 |
| `const f = o.m; f()` | 1 | **undefined** | 方法赋给变量之后，`this` 不再是 `o`。严格模式下是 `undefined`，再取 `.n` 会抛 TypeError |
| `Object.assign` 和 `{...obj}` 谁拷 Symbol | none | **all** | 可枚举的 Symbol 键两个都拷。真正要记的是：两个都是浅拷贝 |
| `typeof Promise.resolve()` | pending 一类 | **object** | `typeof` 看不到 Promise 内部状态。要判用 `instanceof Promise` |
| `async function f(){ return 1 }` 的返回值 | 不是 Promise | **是 Promise** | `async` 永远把返回值包进 Promise |
| `[1,2,3].reduce((a,b) => a+b)` | 不是 6 | **6** | 不给初始值时，第一轮的累积器就是第 0 个元素，不是 0 |
| `[1,[2,[3]]].flat()` vs `.flat(Infinity)` | 前者不是 `[1,2,3]` | **后者是 `[1,2,3]`** | 默认 `flat()` 只展一层，得到 `[1,2,[3]]`；`Infinity` 会展到没有嵌套为止 |
| `addEventListener(type, fn, true)` | 不是捕获 | **捕获** | `true` 是捕获，从外往里。省略或 `false` 才是冒泡 |

打印顺序那道（`setTimeout` / `Promise.then` / 同步）如果你当时没写对，标准顺序是 **cba**：同步，然后微任务，然后宏任务。细节在异步那一课。

## 不计入错误的 2 题

- `querySelectorAll` 写成 `DOMElement`。概念对，名字不对。它返回静态 `NodeList`，不是数组。当时的判分标准只接受 `NodeList` 这一个词，这里不算错。
- 字符串翻转写成 `'c''b''a'` 被归一化判对了。这题算过。

## 先不用管的

类型里的 `typeof null`、`[] == false`，闭包里的 `var` / `let`，这些你第二次或当场是对的。不要为了「系统」把第 1 课重读一遍。
